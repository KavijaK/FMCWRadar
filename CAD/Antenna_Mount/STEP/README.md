# Universal CAD Models (STEP Files)

This folder contains universal 3D CAD files exported in **STEP format (AP214 / AP242)** for cross-platform compatibility.

## File List
* `Final_Assy.STEP` – Complete assembly (dual horn antennas, crossbar, and mounting clips).

## Usage
* Open this file in non-SolidWorks software (e.g., Fusion 360, FreeCAD, Rhino, or web viewers).
* Preserves 3D geometry, individual component structures, and color/material definitions.
