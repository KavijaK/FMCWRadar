# Antenna STEP Models

This folder contains universal 3D CAD models of the standalone horn antenna exported in **STEP format (AP214 / AP242)**.

## File List
* `Antenna_Design.STEP` – Standalone 15 dBi pyramidal horn antenna body.

## Usage
* Compatible with non-SolidWorks software (e.g., Fusion 360, FreeCAD, Rhino, or CAM/3D printing slicers).
* Preserves 3D surface/solid geometry and dimensional accuracy for manufacturing and RF simulations.
